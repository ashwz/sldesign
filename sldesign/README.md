## Description skip-levels design R package "sldesign"

This R package is developed based on the manuscript "Skip-Levels Design: 
A New Phase I Study Design to Improve Dose Selection in Oncology Drug 
Development". 

It includes functions to calculate the sufficient range of the response 
rates that the skip-levels (SL) design performs better than the 
uniformly-assign (UA) design, as well as conduct simulation studies for 
the phase 1 dose-escalation and dose-expansion using the SL design or 
the UA design and find the recommended phase 2 dose admissible region 
using Bayesian 2-parameter logistic regression.

The proposed SL design will result in better performance in correctly 
identifying the doses within the target RP2D admissible region than the 
UA deisgn. We believe this will lead to more efficient phase I oncology 
trials.
